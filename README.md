# 🛒 TaiLocShop - E-commerce Platform

TaiLocShop là một nền tảng thương mại điện tử Full-stack, cung cấp giải pháp mua sắm trực tuyến với đầy đủ các tính năng quản lý đơn hàng, sản phẩm và người dùng.

## 🚀 Tech Stack

**Frontend:**
* ReactJS
* Tailwind CSS
* Axios

**Backend:**
* Node.js & Express
* PostgreSQL (Database)
* Prisma (ORM)
* JWT Authentication

---
